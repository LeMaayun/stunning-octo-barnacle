# Stunning-Octo-Barnacle
SOB is a personal approach to creating a DMX controller for live show production
The main components are:

 > 10 Motorized Faders
 
 	- PID control
 		-> Indivual PWM control
 		-> Individual PWM sintonization
 		
 	- Page system
 		-> DMX Channels page
 		-> Chase/scene page
 		-> Quick "Channel link"
 		
 > 1 DMX Universe
 
 	- Blackout
 	- Fade in/out
 	- Clear
 	- Scenes
 	- Chases
 	
 > 7 inch touch tft display
 
 	- GUI
 	- Fast touch utility (Link channels,Page select)
 	
 > 4 encoders
 
 	- Quick Channel link (for focus, pan and tilt)
 	- Fast page selector
 	
 > 6 buttons
 
 	- Blackout
 	- Clear
 	- Start record
 	- Save step
	- Save Scenes
	- Save Chase
 
 Currently working on: 10 motorized Faders
